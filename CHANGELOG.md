# Changelog

All notable changes to the public research artifact are documented here.

## [Unreleased]

- Human trace audit, clean-environment reproduction, and final author metadata.

## [0.1.0] - 2026-07-30

- Added hybrid BM25/dense/RRF retrieval and feature reranking.
- Added passage/entity graph construction with provenance and corruption tests.
- Added learned marginal rescue value selector.
- Added calibrated preflight and continuation graph-rescuability gates.
- Added frozen 1,000-train/1,000-evaluation protocols for HotpotQA,
  2WikiMultiHopQA, and MuSiQue.
- Added multi-seed and BGE-M3 representation-sensitivity experiments.
- Added full 1,000-query Qwen3-8B reader evaluation with official metrics and
  paired per-query inference for all three datasets.
- Added five-seed graph-corruption robustness aggregation over dropout,
  false-edge, and mixed conditions.
- Added equal-budget independent KG²RAG-style control.
- Added compact analysis results, LaTeX manuscript, Russian theory document,
  licensing notes, release audit, and reproducibility instructions.
- Added an installable Python wheel, bilingual README, GitHub issue forms,
  Russian journal/presubmission guidance, and a social-preview asset.
