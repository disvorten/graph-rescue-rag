# Предварительный запрос в редакцию

Тема: Предварительный запрос о соответствии тематике — селективное графовое
дополнение RAG

Уважаемая редакция журнала «Информатика и автоматизация»!

Прошу уточнить, соответствует ли тематике журнала планируемая полнотекстовая
статья с рабочим названием «Селективное графовое дополнение результатов
гибридного поиска в задачах многошагового ответа на вопросы».

Работа исследует метод, в котором BM25, dense retrieval, fusion и reranker
сначала формируют компактный набор свидетельств, после чего локальное
расширение графа запускается только при прогнозируемой неполноте evidence chain.
Кандидаты ранжируются по условной предельной ценности относительно уже
найденного контекста. Метод сравнивается при одинаковом passage/token budget с
гибридным поиском, безусловным и similarity-only graph expansion, а также с
независимой KG²RAG-style стратегией.

Экспериментальный протокол использует непересекающиеся train/eval подмножества
HotpotQA, 2WikiMultiHopQA и MuSiQue, paired confidence intervals, несколько
seed, два embedding backbones, controlled graph corruption и одинаковый
локальный Qwen3-8B reader. Это controlled pooled-corpus retrieval study, а не
заявка на официальный leaderboard или SOTA.

Программный код, конфигурации и агрегированные результаты планируется открыть
под Apache-2.0; тексты benchmark и model caches распространяться не будут.

При подготовке прототипа, оркестрации экспериментов, анализе и создании
первоначального черновика широко применялись генеративные AI-инструменты.
Перед подачей автор самостоятельно проверяет код, происхождение данных,
статистику, ссылки и traces, повторяет ключевой запуск и заново формулирует
смысловые разделы. AI не указывается автором; использование будет раскрыто в
рукописи.

Буду признателен за ответы на три вопроса:

1. Соответствует ли такая работа тематике и формату полнотекстовой статьи?
2. Допускается ли размещение рукописи в arXiv и/или публичном GitHub до либо во
   время рецензирования?
3. Какую формулировку и расположение disclosure об использовании
   генеративного ИИ рекомендует редакция?
4. Правильно ли мы понимаем, что AI-сгенерированный поясняющий баннер может
   оставаться только в GitHub README, но не должен включаться в представленную
   рукопись, тогда как обычные графики, детерминированно построенные из
   экспериментальных CSV, допустимы?
